# CASCADE: testing LLM judges' chatbot-safety comparisons against psychiatrists in suicidal crises

Code, prompts, psychiatrist ratings and analysis outputs for the paper

> **Psychiatrists overturn LLM judge rankings of chatbot safety in suicidal crises.** Preprint: <ARXIV-URL> *(citation will be updated on publication)*

Sixteen simulated Chinese help-seekers with depressive symptoms conversed with ten chatbots (960 conversations, 9,493 replies). Three psychiatrists rated 180 replies, which were weighted back to the full corpus to test the comparative conclusions reached by two LLM judges.

> **Content warning.** This project concerns suicide and contains simulated conversations about suicidal ideation, including chatbot replies that psychiatrists rated as harmful. If you are in crisis, please contact local emergency services or a crisis line.

## Quick start

```bash
conda env create -f environment.yml
conda activate cascade
python -m pytest -q
```

Tests that need the gated dataset are skipped when it is absent.

## Reproducing the paper

1. Request access to the gated dataset and download it into the repository root so that `runs/`, `cmp_eval_v2/`, `webapp/data/` and `docs/collaboration/*.xlsx` sit next to `tools/` ([DATA_ACCESS.md](DATA_ACCESS.md)).
2. Generate the figures and tables from the frozen reports (written to `paper_final/`):

```bash
python tools/final_figs_a.py --out paper_final
python tools/final_figs_b.py --out paper_final
python tools/final_tables.py
python tools/export_submission_tables.py
```

3. Regenerate the reports themselves with the commands in [REPRODUCE.md](REPRODUCE.md). Bootstrap results match the shipped reports to the reported precision; the fixed random seeds are set in each tool.

## Rerunning the pipeline on new models

[REPRODUCE.md](REPRODUCE.md) lists the commands used to generate the corpus (simulator → target models in two arms → judges). Endpoints are configured in `data/models.yaml`; replace `localhost` and `/path/to/models` with your own vLLM servers and model paths, and put API keys in the environment variables named by `api_key_env` (never in the file). Responses from API models and vLLM batch inference are not bit-for-bit reproducible.

## Third-party data not redistributed

- **PsyQA** (Sun et al., 2021) and **SOS-1K** (Qi et al., 2024) were used only to compare the simulator's language with real text (`reports/sim_vs_real*`). Obtain them from their authors and place them under `PsyQA/` and `corpus/sos1k/` to rerun `tools/sim_vs_real_text.py`.
- Model weights (CPsyCounX, MindChat-Qwen2-4B, SoulChat-R1-Qwen3-8B, InternLM2-chat-7B, Qwen1.5-4B-Chat, Qwen3-8B, and the Qwen3.6-27B / Qwen3.8-27B simulator and judge) are available from their respective Hugging Face repositories.

## Ethics

No real help-seekers were involved; all help-seeker messages were generated by a language model and the simulator was instructed never to state specific suicide methods, doses or locations. Psychiatrists gave informed consent and rated replies without knowing which model produced them.
