- 权重：原 = 抽样格反概率权重（tools/gold_prevalence）；raking = 按抽样格 / 模型 / 臂 × 风险段校准（tools/gold_prevalence_raked.all_weights，自助时每次重抽后重做 raking，含退路）。两套权重共用同一批重抽。
- p 值：自助百分位反转，p = min(1, 2·min(P(d*≤0), P(d*≥0)))，P = (1 + 计数)/(B′ + 1)，B′ = 两组都有样本的重抽数；最小可达 p ≈ 0.0010。对照列「旧 p」= tools/multiplicity 的 CI 正态反推（CI 偏斜 / 截断时不准）。
- 校正：PA、PB 各自 Holm；「合并」= PA + PB 一族 Holm（严格版）。退化（某组无样本 / 自助差值全 0 / 有效重抽 < 50）不进检验。

- 差值单位：百分点；CI = 自助 2.5 / 97.5 百分位。
